
# 🌵 Raízes do Nordeste

## 📌 Sobre o projeto

O **Raízes do Nordeste** é um projeto de desenvolvimento web que simula um sistema de uma rede de lanchonetes especializada em comidas típicas nordestinas.

A aplicação permite que os clientes conheçam os produtos disponíveis, consultem as unidades, adicionem itens ao carrinho e realizem pedidos mediante cadastro ou login.

O projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, organização de código, interatividade e experiência do usuário.

## 🎯 Funcionalidades

- Cadastro e login de usuários.
- Cardápio digital com produtos, preços e descrições.
- Categorias para organização dos produtos.
- Pesquisa de produtos.
- Seleção de diferentes unidades.
- Carrinho de compras.
- Alteração da quantidade de produtos.
- Finalização de pedidos mediante login.
- Histórico de pedidos.
- Programa de fidelidade com acúmulo de pontos.
- Apresentação de promoções.
- Gerenciamento de preferências de privacidade e LGPD.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se a pasta `imgs` contém as imagens utilizadas.
4. Abra o arquivo `index.html` no navegador.
5. Se preferir, utilize a extensão Live Server para executar o projeto.

## 📱 Responsividade

A interface foi desenvolvida para proporcionar uma experiência de navegação em diferentes dispositivos, incluindo computadores, tablets e celulares.

## 🔒 Observação

Este projeto possui finalidade acadêmica e demonstrativa. Os dados são armazenados localmente no navegador por meio do LocalStorage. O sistema não utiliza banco de dados ou autenticação em servidor.
